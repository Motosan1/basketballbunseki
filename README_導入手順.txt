Basketball Touch Analyst Ver.8  導入手順

1. このフォルダの index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png を同じ場所で HTTPS 配信してください。例：GitHub Pages。index.html をファイルアプリから直接開くだけでは PWA としてインストールできません。
2. iPadのSafariで公開したHTTPS URLを開き、ネットワーク接続状態でページの読み込みを完了します。共有→ホーム画面に追加→Webアプリとして開く。
3. ホーム画面のアイコンから起動し、機内モードにして再起動・入力・分析・JSON書き出し・復元をテストしてください。
4. 試合中は入力ごとにIndexedDBへ自動保存します。『試合一覧・新規作成』で複数試合を切替できます。JSONのエクスポートは必ず試合終了時に行ってください。
5. PDFは分析画面の『チーム全体をPDF保存』『選手別をPDF保存』を押してiPadの印刷ダイアログからPDFとして保存してください（端末環境による）。
6. GitHub Pages等にアップロードするのはアプリのファイルだけです。生徒の名前・試合JSONは公開しないでください。

注意：ブラウザ内保存はOSによるデータ消去等で失われる可能性があります。JSONの外部バックアップが必要です。既存Ver.5の記録は同じサイト起点で開いた場合に限り一部移行できることがあります。ローカルHTML版からの移行はVer.5からJSONをエクスポート→Ver.6でインポートしてください。

Ver.7追加機能：記録画面の「✎ 自チーム選手名」で、現在の試合の各選手名を編集・保存できます。背番号を変えず、記録も保持します。更新公開後はiPadで一度オンライン起動し、新版のキャッシュ更新を確認してください。

Ver.8変更点：自チーム・相手チームとも各5〜15名を登録できます。初期登録は各15名（#4〜#18）。出場中5名、ベンチ最大10名。名簿編集時も15人を超える登録を拒否し、JSON読み込みも15名までに制限します。既存の保存済み試合は自動的に人数変更されません。既存の名簿を変更する場合は記録削除の確認が出るため、先にJSONバックアップを取ってください。

Ver.9：試合記録画面の「✎ 相手の背番号」から相手チーム各選手の背番号を0〜99で変更できます。既存の記録は保持します。
